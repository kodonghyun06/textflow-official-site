Quick troubleshooting

  1. Open a normal public http or https page.
  2. Click the TextFlow icon in the Chrome toolbar.
  3. Choose to enable TextFlow for the current tab.
  4. If the page was already open, refresh it and try once more.
  5. To stop, open TextFlow and disable it for the tab.

Site access

Automatic activation is optional. Choose “Allow on this site,” approve Chrome's single-origin permission prompt, and reload the page. You can remove the site from TextFlow settings or Chrome's extension site-access controls at any time.

Pages Chrome protects

Chrome does not allow extensions to run on browser settings pages, the Chrome Web Store, some built-in pages, or the built-in PDF viewer. TextFlow also does not bypass logins, subscriptions, DRM, CAPTCHA, downloads, or server permissions.

Unexpected page behavior

Page structures differ. If a control behaves unexpectedly, disable TextFlow for the tab to restore the page's original behavior, then contact support with a reproducible example.

TextFlow does not collect diagnostic analytics. Support is based only on the information you choose to send.
