Effective July 30, 2026Privacy policy.

TextFlow is designed to restore ordinary browser interactions without turning your reading into data. The extension operates locally and does not collect, sell, or transmit your personal data.

Plain-language summary

  • No account, analytics, advertising, or tracking.
  • No collection of page content, selected text, URLs, or browsing history.
  • No remote code and no sale or transfer of user data.
  • Site approvals and preferences remain in local extension storage.

Scope

This policy applies to the TextFlow Chrome extension and the TextFlow website. It explains what the extension processes, what it stores locally, and how to contact us.

Data the extension collects

TextFlow does not collect personal information, health information, financial or payment information, authentication information, personal communications, location, web history, user activity, or website content.

TextFlow does not send page content, selected text, URLs, browsing history, clicks, keystrokes, or usage measurements to TextFlow or any third party.

Local processing and storage

To perform its single purpose, TextFlow processes page behavior locally in the active browser tab after the user invokes it. If you approve automatic activation for a site, the approved origin and extension preferences are stored using Chrome's local extension storage on your device.

These local settings are used only to provide the extension's requested functionality. They are not transmitted to TextFlow. Removing the extension removes its locally stored settings according to Chrome's normal extension behavior.

Permissions

activeTab

Provides temporary access to the current tab only after an explicit user action, so TextFlow can restore ordinary text interaction without broad permanent access.

scripting

Lets TextFlow inject its packaged, local restoration logic into the current tab. TextFlow does not execute remotely hosted or downloaded code.

storage

Saves local preferences and sites the user explicitly approves for automatic activation.

Optional site access

Chrome requests permission for a specific origin only when the user chooses to allow that site. You can revoke site access through TextFlow or Chrome at any time.

Sharing and sale of data

TextFlow does not sell user data. Because TextFlow does not collect or transmit user data, it does not share such data with third parties for advertising, analytics, credit decisions, or purposes unrelated to the extension's single purpose.

Website delivery

The public website is delivered by a hosting provider. Like most web infrastructure, that provider may temporarily process basic connection information such as an IP address, request time, and requested path to securely deliver the site. TextFlow does not use third-party analytics, advertising pixels, or behavioral tracking on this website.

The embedded demonstration uses YouTube's privacy-enhanced domain. YouTube may process information when you choose to play or open the video under its own policies.

Children

TextFlow is a general-purpose browser accessibility tool and does not knowingly collect personal information from children or anyone else.

Security and changes

TextFlow minimizes risk by collecting no extension user data and by keeping executable code inside the published package. We may update this policy when TextFlow changes. The effective date at the top of this page will be updated when material changes are published.
